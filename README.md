# MythicBoost

Подбор групп Mythic+ для World of Warcraft: Midnight. Аддон запрашивает список
групп у Blizzard, поднимает наиболее полезные наверх и показывает всю выдачу
вместе с составом группы и ключами каждого участника.

Цельная цепочка продукта: **найти группу → собрать пати на свой ключ → понять
результат и сохранить удачных напарников**. Поиск, анализ кандидатов, история и
оптимизатор улучшений работают как ядро. Автоматические действия и замены
интерфейса остаются необязательными дополнениями.

## Установка

Скопировать папку `MythicBoost` в:

```
World of Warcraft/_retail_/Interface/AddOns/MythicBoost
```

Перезапустить игру или выполнить `/reload`.

**Raider.IO** не обязателен, но без него недоступны: ключи участников группы,
счётчик пройденных ключей лидера и вкладка рейтинга гильдии.

## Что делает

При первом открытии аддон не бросает игрока в таблицу фильтров: короткий экран
предлагает выбрать задачу — найти группу, собрать пати на свой ключ или
проверить кандидатов — и сразу ведёт в нужное место. Повторно открыть подсказку
можно кнопкой «Как пользоваться» в шапке окна.

**Подбор групп.** Кнопка «Обновить» запрашивает список у Blizzard и фильтрует
его по твоим настройкам: уровень ключа, рейтинг лидера, число пройденных
ключей +10, размер и возраст группы, свободные роли, танка, лекаря, Bloodlust
и боевого воскрешения. Режим «Только
повышающие рейтинг» оставляет ключи выше личного рекорда: чем выше ключ, тем
сильнее прирост.

Локальные фильтры не удаляют объявления из списка. Подходящие группы
сортируются сверху по приоритету заявки; всё, что не прошло выбранные правила,
остаётся ниже отдельного разделителя в сером виде. Рядом указана причина
отсева. В такую группу всё ещё можно подать заявку вручную, если Blizzard не
снял объявление, группа не заполнена и игроку ранее не отказали.
Обе части поведения настраиваются в `Настройки → Основное`: нижнюю серую
секцию можно скрыть, а ручные заявки из неё — запретить. Даже при скрытой
секции счётчик показывает её реальный размер, чтобы фильтры не создавали
иллюзию пустой выдачи.

После отбора группы сортируются по «приоритету заявки». Это не выдуманный шанс
инвайта: показатель объединяет прирост относительно личного рекорда,
востребованность твоей роли, готовность состава, близость среднего RIO,
свежесть объявления и уверенность в распознанном уровне ключа. Рядом с числом
показаны главные причины, поэтому порядок можно проверить глазами.
Необязательная галочка «Все проходили этот +ключ» оставляет только объявления,
где каждый текущий участник уже закрывал это подземелье на искомом уровне или
выше. Неизвестный профиль не считается подтверждением; по умолчанию строгий
фильтр всегда выключен.

Если в полях «Ключ от» и «Ключ до» стоит одно число, MythicBoost запрашивает
точный уровень через пересечение нечётких диапазонов Blizzard: для `+N`
одновременно ищутся `+(N−1)` и `+(N+1)`. Общая часть двух диапазонов — ровно
`+N`, поэтому защищённое название группы читать не требуется. Тот же способ
используется в режиме повышения рейтинга, когда у выбранных данжей одна цель.

**Подземелья сезона.** Карточки показывают личный рекорд и цель. Клик включает
или исключает подземелье из поиска, «Слабые 3» оставляет три самых отстающих.

**Ключи участников.** Наведение на строку раскрывает таблицу «участники ×
подземелья» с лучшим результатом каждого игрока. На вкладке пати показаны
суммарный и средний RIO, а также осторожный прогноз уровня ключа для группы.
При сборе своего ключа кандидаты сортируются не по одному общему RIO, а по
опыту именно в текущем подземелье: аддон отдельно отмечает подтверждённый
уровень, близкий опыт и риск. Наведение на оценку показывает причину.
«Безопасный уровень» состава считается по опыту каждого участника в конкретном
данже с поправкой на таймер и количество проходок. Слабейшие два игрока имеют
основной вес, поэтому высокий средний RIO больше не маскирует слабое звено.

**Предметы и BiS.** Карточки подземелий отмечают точные Mythic+ BiS-предметы
для Restoration Druid и популярные предметы для остальных специализаций.
Сезонный снимок обновляется скриптом `Tools/UpdateBiSData.ps1`.

**Минимал UI.** Пункт во вкладке настроек включает цельный компактный HUD:
квадратную миникарту, трекер заданий той же ширины, собранные в единый нижний
блок экшен-кнопки, объёмные строки Details и полностью прозрачный чат.
Время находится слева внизу миникарты, а число справа открывает компактную
сетку кнопок установленных аддонов. Пока режим включён, он меняет расположение
части интерфейса; выключение возвращает штатное оформление Blizzard там, где
это поддерживается API игры. Оформление всех игровых подсказок применяется
только вместе с Minimal UI; обычный профиль сохраняет штатный внешний вид
Blizzard.

**Встроенное окно добычи.** Компактный loot-frame показывает предметы цветом
качества, количество и подсказки, собирает их кликом и по желанию открывается
рядом с курсором. В тот же модуль входят голосование за групповую добычу и
компактная лента «кто что получил». Внешние `XLoot_Frame`, `XLoot_Group` и `XLoot_Monitor` следует
отключить, чтобы интерфейсы не дублировались.

**Штатный поиск не захватывается.** Микрокнопка «Поиск группы» всегда открывает
обычное окно Blizzard. Внутри него есть отдельная кнопка `MythicBoost`.

**Рейтинг гильдии.** Отдельная вкладка: тройка лидеров крупно, дальше десятка
основного состава. Данные берутся из локальной базы Raider.IO.

**Напарники и разбор ключа.** После завершения Mythic+ аддон сохраняет только
компактные агрегаты: время, таймер, смерти, штраф, прерывания и контрольные
точки боссов. Отчёт выделяет долю времени, съеденную штрафом за смерти, и
самый длинный участок маршрута между контрольными точками. Вкладка «Напарники» сортирует знакомых игроков по последнему
известному RIO и показывает, сколько ключей вы прошли вместе, процент успешных
таймеров и куда ходили в последний раз. История ограничена 200 игроками и 30
прохождениями.

**Метки перспективных игроков.** Модуль подсказок помечает игроков, чей
экипировочный уровень заметно опережает их текущий рейтинг, и ставит метку над
их полоской здоровья при следующей встрече. База переживает `/reload`,
очищается от записей старше месяца и ограничена 300 персонажами.

**Безопасные фильтры поиска групп.** Фильтрация выполняется только внутри
MythicBoost. Стандартный список Blizzard не переписывается: в Midnight его
результаты содержат secret-поля, и изменение списка из аддона вызывает taint и
ошибки FrameXML. Команда `/mb filter` открывает окно MythicBoost.

## Безопасный первый запуск

На новом профиле включено только ядро MythicBoost и безопасная вставка своего
ключа после открытия пьедестала. Автоприём заданий, призыв и воскрешение,
автопродажа и ремонт, приглашения по шёпоту, компактные фреймы, кастбар,
замена окна добычи, мост RCLootCouncil и глобальный перехват Lua-ошибок
выключены. Каждый пункт включается отдельно в настройках; уже сохранённый
выбор существующего пользователя обновление не перезаписывает.

Порог числа пройденных лидером ключей по умолчанию равен `0` и больше не
растёт скрыто после твоих прохождений. Если такой отбор нужен, его значение
задаётся только вручную в фильтрах.

## Команды

| Команда | Действие |
| --- | --- |
| `/mb` | открыть или закрыть окно |
| `/mb filter` | открыть безопасные фильтры MythicBoost |
| `/mb players` | сколько перспективных игроков сохранено |
| `/mb clear` | очистить базу игроков |
| `/mb modules` | список модулей (зелёные — активные) |
| `/mb reload` | перезагрузить интерфейс |
| `/mb reload <модуль>` | пересобрать один модуль |
| `/mb log on` / `off` / `clear` | журнал событий |
| `/mb log` | последние 20 записей журнала |
| `/mb debug` | что API отдаёт по текущим результатам поиска |

## Если что-то не находится

В Midnight часть данных приходит клиенту защищённой: уровень ключа в заголовке
группы может быть недоступен для чтения. Тогда колонка «Ключ» показывает
прочерк, а фильтр по диапазону такие группы не отбрасывает — лучше показать
лишнее, чем спрятать подходящее.

Проверить, что именно вернул API:

```
/mb log on
```

затем нажать «Обновить» в окне и посмотреть `/mb log`. В журнале видно тип
значения, признак `secret` и разобранный уровень ключа по первым результатам.

## Разработка

Модули регистрируются через `JP:RegisterModule(name, module)` и получают
методы жизненного цикла `Create` → `Enable` → `Disable` → `Destroy`. Ошибка в
одном модуле не роняет остальные: вызовы обёрнуты в `xpcall`.

`UI.lua` — единый визуальный слой: панели, кнопки, флажки, поля, вкладки,
полосы прокрутки, иконки классов и ролей. Новые элементы интерфейса строятся
только через него, иначе окно расползается по стилям.

Локальная пересборка модуля (`/mb reload <модуль>`) использует уже загруженный
Lua-код. После правки `.lua` на диске нужен полный `/reload`, потому что аддон
не может перечитать собственные исходники из файловой системы игры.

`Contracts.lua` — обязательная граница для нестабильных Blizzard API,
secret-значений и лимитов хранения. Модули используют `JP.API`, `JP.Safe*` и
`JP.Limits`, не повторяют позиции возврата и магические числа. Полные правила
для следующих изменений находятся в `ARCHITECTURE.md`.

## Релизная сборка

Чистый архив создаётся командой:

```powershell
python -m pip install -r .\Tools\requirements-dev.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\BuildRelease.ps1
```

Готовый файл появляется в `dist/`. Сборщик берёт только Lua-файлы из TOC,
пользовательскую документацию, лицензии и реально используемые медиаресурсы.
Экспериментальные модули и инструменты разработки в архив не попадают.
Перед упаковкой он проверяет архитектурные контракты, локализацию и
исполняемые smoke-тесты, а после упаковки — фактический состав и безопасные
пути внутри ZIP.
Для замены уже существующего архива передайте сборщику параметр `-Force`.
