# MythicBoost

Подбор групп Mythic+ для World of Warcraft: Midnight. Аддон запрашивает список
групп у Blizzard, отсеивает бесполезные и показывает то, что реально поднимает
рейтинг, вместе с составом группы и ключами каждого участника.

## Установка

Скопировать папку `MythicBoost` в:

```
World of Warcraft/_retail_/Interface/AddOns/MythicBoost
```

Перезапустить игру или выполнить `/reload`.

**Raider.IO** не обязателен, но без него недоступны: ключи участников группы,
счётчик пройденных ключей лидера и вкладка рейтинга гильдии.

## Что делает

**Подбор групп.** Кнопка «Обновить» запрашивает список у Blizzard и фильтрует
его по твоим настройкам: уровень ключа, рейтинг лидера, число пройденных
ключей +10, размер и возраст группы, наличие танка и Bloodlust. Режим «Только
повышающие рейтинг» оставляет ключи выше личного рекорда: чем выше ключ, тем
сильнее прирост.

**Подземелья сезона.** Карточки показывают личный рекорд и цель. Клик включает
или исключает подземелье из поиска, «Слабые 3» оставляет три самых отстающих.

**Ключи участников.** Наведение на строку раскрывает таблицу «участники ×
подземелья» с лучшим результатом каждого игрока.

**Рейтинг гильдии.** Отдельная вкладка: тройка лидеров крупно, дальше десятка
основного состава. Данные берутся из локальной базы Raider.IO.

**Метки перспективных игроков.** Модуль подсказок помечает игроков, чей
экипировочный уровень заметно опережает их текущий рейтинг, и ставит метку над
их полоской здоровья при следующей встрече. База переживает `/reload`,
очищается от записей старше месяца и ограничена 300 персонажами.

**Фильтр стандартного поиска групп.** В окне Blizzard прячутся лидеры, у
которых пройдено меньше указанного числа ключей +10. Порог задаётся полем над
кнопкой фильтра и автоматически растёт после каждого сданного ключа.
Выключается командой `/mb filter`.

## Команды

| Команда | Действие |
| --- | --- |
| `/mb` | открыть или закрыть окно |
| `/mb filter` | фильтр в стандартном поиске групп вкл/выкл |
| `/mb players` | сколько перспективных игроков сохранено |
| `/mb clear` | очистить базу игроков |
| `/mb modules` | список модулей (зелёные — активные) |
| `/mb reload` | перезагрузить интерфейс |
| `/mb reload <модуль>` | пересобрать один модуль |
| `/mb log on` / `off` / `clear` | журнал событий |
| `/mb log` | последние 20 записей журнала |
| `/mb debug` | что API отдаёт по текущим результатам поиска |

## Если что-то не находится

В Midnight часть данных приходит клиенту защищённой: уровень ключа в заголовке
группы может быть недоступен для чтения. Тогда колонка «Ключ» показывает
прочерк, а фильтр по диапазону такие группы не отбрасывает — лучше показать
лишнее, чем спрятать подходящее.

Проверить, что именно вернул API:

```
/mb log on
```

затем нажать «Обновить» в окне и посмотреть `/mb log`. В журнале видно тип
значения, признак `secret` и разобранный уровень ключа по первым результатам.

## Разработка

Модули регистрируются через `JP:RegisterModule(name, module)` и получают
методы жизненного цикла `Create` → `Enable` → `Disable` → `Destroy`. Ошибка в
одном модуле не роняет остальные: вызовы обёрнуты в `xpcall`.

`UI.lua` — единый визуальный слой: панели, кнопки, флажки, поля, вкладки,
полосы прокрутки, иконки классов и ролей. Новые элементы интерфейса строятся
только через него, иначе окно расползается по стилям.

Локальная пересборка модуля (`/mb reload <модуль>`) использует уже загруженный
Lua-код. После правки `.lua` на диске нужен полный `/reload`, потому что аддон
не может перечитать собственные исходники из файловой системы игры.
