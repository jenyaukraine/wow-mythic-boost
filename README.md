# MythicBoost

MythicBoost — помощник для Mythic+ и компактный настраиваемый HUD для
**World of Warcraft Retail 12.1 (Midnight)**. Аддон помогает найти группу,
оценить кандидатов, разобрать прохождение, спланировать улучшения экипировки и
оставляет опасные автоматические действия под явным контролем игрока.

Текущая версия: **2.4.133**.

В поиске групп доступны список с постоянной высотой строк, автоматическая
роль по специализации и дополнительные фильтры.
Нажми поле «Любой ключ», введи диапазон штатным вводом Blizzard, затем
«Обновить». Кнопка «Рейды» переключает поиск на рейды с фильтрами сложности,
боссов и состава. «Создать объявление» открывает штатную форму своего ключа
с заполненными подземельем и уровнем.
[Сравнение возможностей с Shortlist и ограничения](docs/shortlist-coverage.md).

В лаборатории талантов появился режим **«Ценность очка»**: оценка постоянных
усилений друида «Исцеление» по записанным заклинаниям, список вложенных очков и
кандидатов, формулы и статус доступности пути. `~` обозначает модель одного очка,
`=` — долю отдельного источника. Таланты без оценки перечислены в подробностях.
По умолчанию учитываются все сохранённые ключи той же сборки; можно сузить отбор
до карты и уровня последнего ключа. Проверены семь
постоянных усилений для 12.1.0.69587; условные эффекты и весь оптимальный билд
эта модель не рассчитывает. [Методика и ограничения](docs/talent-point-models.md).

## Установка

Скопируйте папку `MythicBoost` в:

```text
World of Warcraft/_retail_/Interface/AddOns/MythicBoost
```

Перезапустите игру или выполните `/reload`. Основное окно открывается командой
`/mb` или кнопкой `MythicBoost` внутри стандартного поиска групп Blizzard.

**Raider.IO необязателен.** Без него работают интерфейс, поиск и большая часть
аналитики, но недоступны ключи участников, статистика пройденных подземелий и
рейтинг гильдии на основе локальной базы Raider.IO.

## Возможности

### Поиск и сбор группы

- Фильтры по уровню ключа, рейтингу и опыту лидера,
  свободным ролям, танку, лекарю, Bloodlust и боевому воскрешению.
- Подходящие объявления сортируются сверху по объяснимому приоритету заявки.
  Активные заявки закреплены перед ними. «Доп. фильтр» открывает состав,
  специализации, стили и языки.
  Не прошедшие фильтры остаются ниже серым списком с причиной —
  MythicBoost не создаёт иллюзию пустой выдачи.
- Поиск по уровню использует введённый игроком диапазон в штатном поле Blizzard.
  Аддон сохраняет его при обновлении и не записывает текст в защищённое поле.
- Карточки сезонных подземелий показывают личный рекорд и цель; кнопка
  «Слабые 3» оставляет три наиболее отстающих данжа.
- При сборе своего ключа кандидаты оцениваются по опыту именно в выбранном
  подземелье. Безопасный уровень состава сильнее учитывает двух самых слабых
  участников, поэтому высокий средний RIO не маскирует риск.
- «Собрать пати» сразу открывает форму своего ключа со стилем «Серьёзный».
  Режимы Mythic+/рейды находятся над карточками. У рейдовых групп доступен
  портрет первого неубитого босса по атласу, если Blizzard предоставил данные.
- Рейтинг гильдии показывает текущий рейдовый прогресс персонажа из Raider.IO;
  подробности по сложностям доступны при наведении.

Стандартный список Blizzard не переписывается. В Midnight часть LFG-данных
является `secret`, поэтому фильтрация и сортировка выполняются только внутри
окна MythicBoost без небезопасного вмешательства во FrameXML.

### Аналитика и прогресс

- В штатном дереве каждый талант показывает сумму своих связанных заклинаний,
  делённую на общий результат тех же замеров. Нажатие на процент открывает
  отдельные прохождения: сумму таланта, общий итог и процент. Подсказки разбирают
  числитель по заклинаниям; повторные источники не суммируются дважды.
  Учитываются замеры той же специализации, версии и ранга из истории до 30 ключей.
  Неполные данные отмечены жёлтым и «~», неизвестные источники остаются без подписи.
  Доля источников не подменяется разницей общего HPS/DPS сборок. Для пассивного
  усиления без отдельного источника вклад не выделен.

- Ключи участников и матрица «игрок × подземелье» при наведении.
- Рейтинг гильдии по локальным данным Raider.IO.
- «Напарники»: совместные ключи, процент прохождений в таймер и последний
  общий данж.
- Компактная история до 30 прохождений и 200 знакомых игроков.
- Карточка последнего ключа отдельно показывает результат, время, смерти,
  штраф, прерывания и главный измеримый провал без растянутых строк и пустот.
- Метки перспективных игроков, чей уровень экипировки заметно опережает
  текущий рейтинг. База ограничена 300 персонажами и очищается по сроку жизни.
- Сезонные BiS-подсказки и анализ предметов по активной специализации.
  Встроен снимок AutoBiS 1.2.1 / Wowhead от 2026-09-08 для 40 специализаций;
  отдельный AutoBiS не требуется. Для M+ и рейдов используются соответствующие
  списки, если они есть; иначе общий список с подписью варианта.
- Карточки рейдов показывают число целей и BiS, подсказки рейдов и боссов —
  полезные предметы. Предпросмотр использует наивысшую отмеченную сложность
  поиска (обычную, если фильтр сложности не задан), явно указанную в подсказке.
  Уровень сравнивается отдельно для каждого предмета с учётом вещей в сумках.
  Это список целей по гайду и ilvl, а не симуляция прироста DPS/HPS.

Обновить встроенную базу из установленного AutoBiS:
`python Tools/ImportAutoBiS.py "D:/Games/World of Warcraft/_retail_/Interface/AddOns/AutoBiS"`.
Подставьте путь к своей папке AutoBiS; путь выше — пример для Windows.
Дату встроенного снимка можно увидеть в подсказке добычи рейда или в `MythicBoost/Data/AutoBiS.lua` (`updatedAt`).
Обновление внешнего AutoBiS само по себе снимок MythicBoost не меняет.
Снимок пересобирается вместе с аддоном и входит в релиз как обычные данные MythicBoost.

### Улучшения и валюта

Калькулятор улучшений читает актуальные дорожки, цены и гербы из API игры,
когда эти данные доступны у мастера улучшений. Он показывает оставшиеся шаги,
золото, сколько гербов есть и сколько не хватает. При наведении сначала
открывается штатная подсказка валюты Blizzard, дополненная текущим сезонным
лимитом; названия и ID гербов не зашиты в код под один сезон.

### Компактный HUD

На действительно новом профиле включается готовый компактный пресет:

- квадратная миникарта с названием зоны сверху;
- индикатор очереди в нижнем левом углу, часы точно по центру и штатный Addon
  Compartment в нижнем правом углу;
- один ровный ряд системных micro-кнопок сразу под миникартой, без промежутков;
- трекер заданий той же ширины под рядом кнопок;
- капсулы игрока и цели с портретом, здоровьем, ресурсом, классовым медальоном,
  уровнем, аурами и встроенной индикацией каста; цвет здоровья по классу
  включается отдельной необязательной галочкой;
- отдельный компактный кастбар и окно добычи.

Старые профили сохраняют прежние настройки: обновление не включает визуальные
модули самовольно. Чат, корневые позиции панелей действий, штатные бафы и
дебафы, сторонние кастбары и встроенный Blizzard Damage Meter не
перехватываются. Положение штатных аур всегда остаётся за Blizzard Edit Mode;
при установленном BasicMinimap владение миникартой остаётся у него.

Когда компактная капсула заменяет стандартный фрейм и показывает собственный
ряд аур, штатная лента временно скрывается без изменения её раскладки. После
отключения капсулы или её аур Blizzard-лента возвращается в сохранённую Edit
Mode позицию, поэтому одинаковые значки не дублируются на экране.

Общий «Режим перемещения интерфейса» разблокирует капсулы, кастбар, трекер
бафов и окно эпохального ключа. После расстановки режим следует выключить.

### Мини-трекер положительных аур

Во вкладке `Настройки → Трекер бафов` можно:

1. Добавить один или несколько эффектов по spell ID, ссылке на заклинание или
   точному локализованному имени.
2. Нажать «Сканировать» и применить способность — следующий успешный каст
   игрока будет найден, подписан и сразу добавлен, после чего сканирование
   остановится.
3. Выбрать показ активных бафов или предупреждение об отсутствующих, секунды,
   заряды и игровую иконку.
4. Настроить цвет, высоту, ширину, расстояние от персонажа, промежуток,
   пульсацию и размер цифр.
5. Выбрать одну из трёх форм: «Крыло», «Вихрь» или оригинальный BLP-«Лунар».

Шкалы зеркально располагаются по бокам персонажа и опустошаются снизу вверх
вместе со временем бафа. Предпросмотр обновляется сразу. В бою аддон проверяет
только заранее известные положительные ауры игрока через точечный разрешённый
API и не перебирает глобальный список аур.

### Добыча

Встроенный модуль даёт компактное окно предметов у курсора, штатные иконки
Need/Greed/Disenchant/Transmog/Pass для группового броска и короткий монитор
полученной добычи, валюты и денег. Групповой бросок использует цветное
стеклянное оформление качества предмета и лёгкий перелив без отдельного
фонового таймера. Монитор растёт вверх, хранит не более шести
временных записей и не добавляет лишний префикс «Ваша добыча».

Если используются `XLoot_Frame`, `XLoot_Group` или `XLoot_Monitor`, отключите
дублирующие модули, чтобы два аддона не боролись за одни окна.

## Первый запуск и безопасность

Новая установка сразу включает все рабочие модули: фирменный HUD, поиск,
аналитику, трекер бафов, SmartClick, помощник прерывания, журнал ошибок,
мост RCLootCouncil и автоматику заданий, ремонта, продажи серого хлама,
призыва, воскрешения вне боя и приглашений по шёпоту.

Перетаскивание, предпросмотры и дополнительные ограничения фильтров не
включаются. Выбранные пользователем отключения и позиции сохраняются при
обновлении. Для пользовательского трекера нужно выбрать наблюдаемые эффекты,
для SmartClick — назначить макрос на удобное нажатие. При установленном
RCLootCouncil или отдельном сборщике ошибок их обработчики не дублируются.

Если включены авторемонт и вывод итога в чат, внутри рейда после каждой починки
показываются стоимость текущего ремонта и накопленная строка «За время рейда».
Сумма сбрасывается при выходе из рейдового инстанса.

## Команды

| Команда | Действие |
| --- | --- |
| `/mb` | открыть или закрыть MythicBoost |
| `/mb filter` | открыть безопасные фильтры MythicBoost |
| `/mb players` | показать число сохранённых перспективных игроков |
| `/mb clear` | очистить базу перспективных игроков |
| `/mb modules` | показать состояние модулей |
| `/mb reload` | перезагрузить интерфейс |
| `/mb reload <модуль>` | пересобрать модуль из уже загруженного Lua-кода |
| `/mb frames` | включить или выключить компактные фреймы |
| `/mb frames reset` | сбросить позиции фреймов игрока и цели |
| `/mb smartclick` | диагностировать заклинания, макрос и атрибуты SmartClick |
| `/mb errors` | открыть внутренний журнал ошибок |
| `/mb errors clear` | очистить внутренний журнал ошибок |
| `/mb log on` / `off` / `clear` | управлять диагностическим журналом событий |
| `/mb log` | показать последние 20 событий |
| `/mb debug` | вывести снимок структуры результатов LFG API |
| `/mb restorefilter` | вернуть сохранённый фильтр стандартного окна групп |
| `/mb testroll` | показать безопасный тест группового броска |

После изменения Lua-файлов на диске нужен полный `/reload`: локальная команда
пересборки не может перечитать исходники из файловой системы игры.

## Диагностика

Если поиск ведёт себя неожиданно, включите `/mb log on`, обновите выдачу и
посмотрите `/mb log`. Журнал показывает типы полученных значений, признак
`secret` и доступный результат разбора.

Если появляется игровая Lua-ошибка, включите перехват в
`Настройки → Система`, воспроизведите проблему и откройте `/mb errors`.
Исправленные старые сигнатуры MythicBoost удаляются точечно; сторонние и новые
ошибки не скрываются.

Актуальная версия защищает `Show/Hide`-хуки от встречной рекурсии,
не создаёт фреймы внутри обхода `EnumerateFrames`, ограничивает историю и кэши,
а страховочное обслуживание интерфейса выполняет не чаще одного раза в пять
секунд. Трекер бафов обновляет цифры с интервалом 0,1 секунды и переиспользует
восемь заранее созданных слотов вместо накопления новых объектов.

## Разработка

Модули регистрируются через `JP:RegisterModule(name, module)` и проходят цикл
`Create → Enable → Disable → Destroy`. Нестабильные Blizzard API, проверки
`secret` и лимиты хранения сосредоточены в `Contracts.lua`; визуальные
компоненты создаются через `UI.lua`. Подробные правила находятся в
[`ARCHITECTURE.md`](ARCHITECTURE.md).

Проверки проекта:

```powershell
python .\Tools\CheckLocalization.py
python .\Tools\CheckArchitecture.py
python .\Tools\TestMythicBoost.py
```

Релизная сборка:

```powershell
python -m pip install -r .\Tools\requirements-dev.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tools\BuildRelease.ps1
```

Архив появляется в `dist/`. Сборщик берёт только файлы из TOC, документацию,
лицензии и явно перечисленные медиаресурсы, затем проверяет состав ZIP.
