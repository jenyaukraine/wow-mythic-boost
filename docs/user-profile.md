# Профиль пользователя: World of Warcraft

## Используемые аддоны

Подтверждено пользователем скриншотами включённых аддонов 8 сентября 2026 года:

- MythicBoost
- Simulationcraft
- Auctionator
- DandersFrames (включая DandersFrames Options)
- Platynator
- Chattynator
- Pawn
- BigWigs (включая Midnight Lair Bosses)
- LittleWigs (на скриншоте виден модуль Wrath of the Lich King)
- Mythic Dungeon Tools (MDT, включая модуль UI)
- Raider.IO: основной аддон и базы Europe для Mythic Plus, Raiding и Recruitment

Базы Raider.IO других показанных регионов выключены. Модули с загрузкой по требованию включены, но не обязательно загружены постоянно. Скриншоты показывают часть списка, поэтому перечень не считается полным.

Учитывать этот набор при проверке совместимости MythicBoost. Не менять настройки и файлы других аддонов без отдельного запроса пользователя.
